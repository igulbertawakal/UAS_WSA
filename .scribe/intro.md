# Introduction

RESTful API mini e-commerce untuk pengelolaan kategori dan produk.

<aside>
    <strong>Base URL</strong>: <code>http://localhost/UAS_WSA/public</code>
</aside>

    API ini dibuat untuk proyek akhir Web Service Application. Login terlebih dahulu untuk mendapatkan bearer token, lalu gunakan token tersebut pada endpoint Categories dan Products.

    <aside>Gunakan akun seed <b>admin@uas-wsa.test</b> dengan password <b>password</b> untuk pengujian.</aside>
